# Security

If you find a vulnerability in Tabora (the browser, the apps, the account server or the website),
please report it privately: open the repository it concerns, go to **Security → Report a
vulnerability** and describe what you found. If you are not sure which repository it belongs to,
use [Tabora-App/browser](https://github.com/Tabora-App/browser/security/advisories/new).

Please do not open a public issue for a vulnerability and do not test it against other people's
accounts or data.

A useful report says what is affected, how to reproduce it and what an attacker gains. We read
every report and reply in the same thread.

Published audits of the code are in
[browser/docs](https://github.com/Tabora-App/browser/tree/main/docs).
