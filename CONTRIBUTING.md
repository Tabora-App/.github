# Contributing

Thank you for looking into Tabora. Issues and pull requests are welcome in every repository of the
organization.

## Reporting a problem

Open an issue in the repository the problem belongs to:

- the browser on a computer, the Android app or the web app: [browser](https://github.com/Tabora-App/browser/issues)
- the iPhone app: [ios](https://github.com/Tabora-App/ios/issues)
- accounts, sync storage, mail delivery: [server](https://github.com/Tabora-App/server/issues)
- the website: [site](https://github.com/Tabora-App/site/issues)

Say which version and platform you use, what you did, what you expected and what happened. A
screenshot helps. Vulnerabilities are reported privately, see [SECURITY.md](SECURITY.md).

## Changing the code

- Each repository's README explains how to build and check it.
- Keep a change to one thing and explain in the pull request what it does and how you checked it.
- Commit messages, comments in new code and documentation are in English.
- The source language of the interface is Russian: strings in the code are written in Russian and
  translated through dictionaries (`i18n/`). A new string needs its English, Ukrainian and Spanish
  translations; the build checks this.
- Code is licensed under the Mozilla Public License 2.0. By contributing you agree to license your
  change under it.
